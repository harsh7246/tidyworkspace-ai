TidyWorkspace AI — Settings

1. Provider & API key

Your key is stored locally in this browser profile only (chrome.storage.local) and is never sent anywhere except directly to your chosen provider's API.

2. Models per feature

Optional — defaults are a cheaper/faster model for renaming and a stronger one for grouping.

4. Privacy & data sent

On every sweep, tab titles and domains (not full URLs) for ungrouped tabs are sent to your selected provider so it can suggest groupings. On every non-excluded download, the filename, MIME type, and the active tab's title/domain are sent so it can suggest a clean filename. Nothing is sent to Anthropic or any TidyWorkspace-run server — only to the provider you configure above, using your key.
